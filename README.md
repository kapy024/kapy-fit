# kapy-fit — Registro de Hierro

Bitácora personal de entrenamiento en una sola página HTML, sin dependencias ni backend.

- Rutina de 7 días (empuje, pierna/glúteo, core, bíceps, dorsales, pierna, descanso)
- Registro de peso, series y reps por ejercicio, con historial
- Temporizador de descanso y enlaces de técnica por ejercicio
- Todo se guarda en `localStorage` del navegador (los datos no salen del dispositivo)

## Uso

Abrir `index.html` en el navegador, o publicarlo con GitHub Pages (Settings → Pages → branch `main`, carpeta `/`).
